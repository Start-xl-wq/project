> 适用范围：USB 2.0 High-Speed（480Mbps，UI = 2.083ns）TX 眼图调优
> 寄存器命名以 Synopsys DWC USB2 PHY（femtoPHY/picoPHY 系列）为准，多数 SoC 沿用此命名，bit 宽以你的 PHY databook 为准。

## 一、眼图判读标准（Mask 模板）

### 1.1 眼图组成

| 组成 | 是什么 | 作用 |
|------|--------|------|
| **波形轨迹带（trace）** | 成千上万个 UI 波形头尾对齐叠加成的"带子" | 实测信号 |
| **Mask（模板）** | Spec 规定死的图形 | 判决用的违规区 |

### 1.2 Mask 的两条规则

```
   上限制线 ─────────────────────────────────   ← 规则一：轨迹不得冲出

                P2 ____________ P3
                  /            \
                 /              \
           P1  <      禁区       >  P4           ← 规则二：轨迹不得进入
                 \   (六边形)   /
                  \____________/
                P6              P5

   下限制线 ─────────────────────────────────   ← 规则一：轨迹不得冲出
```

- **规则一（上下限制线）**：波形轨迹**不能冲出**上/下限制线。
- **规则二（内六边形禁区）**：波形轨迹**不能进入**中间的六边形禁区（上下左右均不可）。
- P1 / P4 为左右尖点（约 0.15 / 0.85 UI 处，0 mV），对应信号翻转的 crossover 区，因此禁区两端收尖；上下平顶为眼高判决区。
- 全部轨迹待在限制线与六边形之间的"环形通道"内 = Pass；违反任一条 = Fail。

### 1.3 近端 vs 远端（必须都测）

| 测试点 | 测法 | 主要暴露 | 调整倾向 |
|--------|------|---------|---------|
| **近端（Near-end）** | 连接器处直接测 | **过冲**（冲出限制线） | 倾向"减" |
| **远端（Far-end）** | 过标准线缆+负载后测 | **眼闭合**（顶进禁区） | 倾向"加" |

> ⚠️ 两点调整方向常相反。**先解决近端过冲，再解决远端闭合**，顺序反了会互相打架。

### 1.4 Mask 坐标

各顶点（UI / mV）查 **USB 2.0 Spec Figure 7-9 / 7-10**（Template 1 近端 / Template 2 远端）。

## 二、违规现象 → 病因 → 药方 总表

**核心决策逻辑：先看违规方式，再对号入座。**

| # | 违规现象 | 违反 | 本质 | 主要病因 | 第一药方 | 第二药方 |
|---|---------|------|------|---------|---------|---------|
| 1 | 冲出**上/下限制线** | 规则一 | 幅度过大/过冲 | 边沿太陡、预加重过大、短走线幅度偏高 | `TXRISETUNE0` 放缓边沿 | `TXPREEMPAMPTUNE0`↓、`TXVREFTUNE0`↓ |
| 2 | **上下顶进**禁区 | 规则二 | 眼高不足 | 幅度太小、（远端）损耗大 | `TXVREFTUNE0`↑ | （远端）`TXPREEMPAMPTUNE0`↑ |
| 3 | **左右挤进**禁区 | 规则二 | 眼宽不足 | 抖动大、时钟脏、ISI | 查 refclk / PLL | （ISI 型）`TXPREEMPAMPTUNE0` |
| 4 | 波形**发毛/振铃/毛刺** | 多伴规则一 | 信号完整性差 | 阻抗失配、边沿太陡、电源噪声 | `TXRESTUNE0` 匹配 / `TXRISETUNE0` | 板级：串阻、去耦、90Ω 差分 |
| 5 | **crossover 偏移**（上下不对称） | — | 差分不对称 | 交叉点电压偏 | `TXHSXVTUNE0` | 查差分对称性 |
| 6 | **误断连/断连不灵** | — | 门限问题 | 断连检测阈值不当 | `COMPDISTUNE0` | — |

### 三个反直觉点

1. **上下方向有两种相反的病**：冲出限制线 = 太高 → 减；顶进禁区 = 太低 → 加。先分清"往外冲"还是"往里顶"。
2. **预加重是双刃剑**：救"眼高不足"，恶化"过冲"。调优就是找平衡。
3. **左右挤进（眼宽）是抖动/时钟问题**，幅度类 TUNE 方向完全不对，别在幅度上瞎调。

## 三、寄存器详解

### 3.1 幅度类

**`TXVREFTUNE0`** — HS 发送摆幅（DC level）
- 整体抬/压发送电压，近似线性。典型 4 bit。
- 眼高不足 → ↑；过冲 → ↓。

### 3.2 预加重类（补损耗用）

**`TXPREEMPAMPTUNE0`** — HS 预加重幅度
- 跳变沿处额外加流，补偿线缆/走线高频损耗，收窄 ISI。典型 2 bit（00 = 关）。
- 远端损耗闭合 / ISI → ↑；近端过冲 → ↓。
- ⚠️ **短走线板子开预加重 = 纯加过冲**。近端撞限制线时先怀疑它。

**`TXPREEMPPULSETUNE0`** — 预加重脉宽（1x / 2x）
- 控制预加重作用时长，典型 1 bit。配合上者微调补偿强度。

### 3.3 边沿 / 平滑类

**`TXRISETUNE0`** — HS 上升/下降沿速率
- 控制边沿陡缓，典型 2 bit。
- 过冲/振铃/EMI → 放缓边沿（三者常一起改善）。
- ⚠️ 放太缓 → 斜边压窄眼宽，需权衡。

**`TXRESTUNE0`** — HS 源端接阻抗（约 45Ω）
- 匹配源阻抗、抑制反射，典型 2 bit。
- 周期性振铃/反射 → 调匹配。反射叠加也会表现为抖动（左右挤进），别只当幅度问题。

### 3.4 对称 / 交叉点

**`TXHSXVTUNE0`** — HS crossover 电压
- 调 D+/D− 交叉点电压，典型 2 bit。
- 眼图上下不对称、crossover 偏出规范窗口时调。

### 3.5 检测门限类（不影响眼形，影响功能）

| 寄存器 | 作用 | 典型宽度 | 何时调 |
|--------|------|---------|--------|
| `COMPDISTUNE0` | HS 断连检测阈值 | 3 bit | 误断连 / 断连不灵 |
| `SQRXTUNE0` | RX squelch 检测阈值 | 3 bit | 接收灵敏度 / 噪声误触发 |
| `OTGTUNE0` | VBUS valid 门限 | 3 bit | OTG 场景 VBUS 判定 |
| `TXFSLSTUNE0` | FS/LS 源阻抗 | 4 bit | 全/低速信号质量（非 HS 眼图） |

### 3.6 时钟 / 抖动类（眼宽问题的源头）

眼宽不足（左右挤进）多数是抖动，**先查时钟源，源头脏后面全白调**：

| 项目 | 说明 |
|------|------|
| refclk 质量 | 示波器直测参考时钟抖动，第一步 |
| PLL*TUNE（PLLI/PLLP/PLLB 等） | PLL 调节，降 RJ |
| 供电去耦 / 纹波 | 电源噪声引入抖动 |
| `GFLADJ` | SOF 帧长微调，修 refclk 频偏 |
| `FSEL` / `REFCLKSEL` | 参考时钟频率/来源选择 |
| `COMMONONN` | suspend 期间 PLL 常开，避免掉电扰动 |

## 四、标准调试流程（SOP）

```
① 进 test mode，抓 test_packet pattern
② 判读：撞哪里？（冲出限制线 / 上下顶进 / 左右挤进 / 发毛）
③ 对照总表找病因 → 锁定寄存器
④ 从厂商默认值起步，只针对本板非标处偏移（别从 0 试）
⑤ 每次只改一个 field，记录 Δ眼高 / Δ眼宽 / Δ过冲
⑥ 近端过冲先解决 → 再解决远端闭合（顺序别反）
⑦ 软件到头仍不行 → 查硬件（走线 / 串阻 / 差分阻抗 / 去耦 / 时钟）
```

进 test mode（Linux）：

```bash
echo test_packet > /sys/kernel/debug/xxxx.usb/testmode
```

### 五条铁律

1. **先分清违规方式再动手**——冲出/顶进/挤进是三种不同的病。
2. **每次只改一个 field**——TUNE 之间交叉影响，同改分不清因果。
3. **从默认值偏移，不从 0 起**——你只补自己板子与典型场景的差异。
4. **近端减、远端加，顺序不能反。**
5. **TUNE 只有 2~4 bit**——救不了走线/阻抗/时钟的硬件灾难。
