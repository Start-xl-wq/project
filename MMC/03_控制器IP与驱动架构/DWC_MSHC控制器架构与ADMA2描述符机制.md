# DWC MSHC 控制器架构与 ADMA2 / ADMA3 描述符机制

> **定位**：Synopsys DesignWare Mobile Storage Host Controller (DWC MSHC) 是大多数高端 SoC 内部集成的主流 MMC/SD 控制器 IP。理解其内部架构与 ADMA 描述符是写好驱动与排查 DMA 搬移死锁的关键。

---

## 2. ADMA2 (Advanced DMA 2) 描述符环机制

与早期的 SDMA（只能单次搬移一个连续物理页、频繁依赖 CPU 中断中断）不同，**ADMA2 引入了 Scatter-Gather（分散/聚合）链表**，允许一次将多段不连续的物理内存数据连续打上总线。

一个标准的 32 位 ADMA2 描述符占用 **8 字节**：
```text
Bit 63 ─────────── 32 31 ──────────────── 16 15 ────── 6 5 4 3 2 1 0
┌────────────────────┬─────────────────────┬────────────┬─┬─┬─┬───┐
│  32-bit 物理地址   │    16-bit 长度      │  保留位    │I│E│X│Act│
│  (Data Address)    │    (Length ≤ 64KB)  │            │N│N│V│   │
│                    │                     │            │T│D│L│   │
└────────────────────┴─────────────────────┴────────────┴─┴─┴─┴───┘
```

### 关键属性控制位 (Attribute Bits)：
* **Act (Action, 2-bit)**：
  * `00` (Nop)：空操作，跳过；
  * `10` (Tran)：**数据传输**（核心，按指定的物理地址与长度发起 DMA）；
  * `11` (Link)：**链表指针**（当前描述符不传数据，其地址字段指向下一个描述符表的基地址）。
* **END (End of Table, 1-bit)**：
  * `1`：标识这是整笔传输链表的最后一个描述符，搬运完成后硬件自动停止。
* **INT (Interrupt, 1-bit)**：
  * `1`：当硬件搬运完当前描述符后，向 CPU 上报中断（通常仅在最后一个描述符置 1，避免多中断风暴）。

---

## 3. ADMA3 进阶亮点 (面向 64 位与多队列)
* 支持 64 位寻址（物理地址扩展为 64-bit）；
* **集成命令描述符 (Command Descriptor)**：允许将命令下发（CMD）、参数与数据传输全部封装进统一的描述符环中，进一步将 CPU 从中断分发中彻底解脱出来。

---

## 4. 芯片原厂驱动编写避坑红线
1. **64KB 长度溢出**：
   * ADMA2 长度字段仅 16 位，单次描述符最大支持 $2^{16} = 65536$ 字节（64KB）；
   * 如果上层提交的物理块超过 64KB，驱动必须在软件层循环拆片为多个小于等于 64KB 的描述符。
2. **地址与长度 4 字节对齐**：
   * 某些旧版 DWC 控制器硬件限制起始物理地址与长度必须 4 字节（32-bit）对齐；若遇到非对齐 buffer，必须使用内核 bounce-buffer（中转缓冲区）拷贝。
